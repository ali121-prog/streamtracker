# Stream Tracker (client-only Fabric mod, MC 1.20.1)

Requires: Fabric Loader + Fabric API. Optional: Mod Menu + Cloth Config (settings screen).

Build the jar with no installs: upload this folder to a GitHub repo, open the Actions tab,
run "build", download the "streamtracker-jar" artifact. Put the .jar in .minecraft/mods.

Commands: /streamtracker test <name> <amount> | lines | addregex <regex> | reset
Config: .minecraft/config/streamtracker.json
